# Working in this repository

## Commits

**Do not add `Co-Authored-By` trailers to commits.** No `Co-Authored-By: Claude`
line, and no "Generated with Claude Code" line. Commits are authored by the
repository owner alone.

Write the message as the project already does: a short imperative subject, then
a body explaining *why* the change was made rather than restating the diff.
